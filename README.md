# Personal Copilot (Offline, Open Source)

This project is a **fully local Retrieval-Augmented Generation (RAG) system** that runs on your laptop using only open‑source software.

You place documents into a folder, the system indexes them, and you can then ask questions in the terminal. Answers are generated by a **local language model**, using only your documents as context.

This is not model training. The system does **retrieval + reasoning**: it searches your documents and uses a local LLM to synthesize an answer.

---

## What this project does

• Reads `.txt`, `.md`, and `.pdf` files from a folder
• Splits documents into chunks
• Converts chunks into embeddings (vectors)
• Stores them in a local FAISS index
• Retrieves relevant chunks for each question
• Uses a local LLM (via `llama.cpp`) to answer
• Runs entirely offline in the terminal

Use cases:

* Personal knowledge base
* Searching notes, PDFs, docs
* Private document Q&A
* Learning RAG fundamentals without cloud dependencies

## Requirements

* Python 3.10+
* Windows / Linux / macOS
* At least 6–8 GB RAM recommended
* CPU only (no GPU required)

---

## Setup instructions

### 1. Clone or create the project folder

```bash
mkdir local-rag
cd local-rag
```

Create subfolders:

```bash
mkdir documents models index
```

---

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

If installation succeeds, skip to step 3.

---

### 3. Download a local LLM

This project uses **GGUF** models compatible with `llama.cpp`.

Recommended for low‑RAM laptops (<8 GB):

* TinyLlama 1.1B (Q4)

Place the downloaded `.gguf` file into:

```
models/
```

Example:

```
models/tinyllama-1.1b-chat.Q4_K_M.gguf
```

Update `MODEL_PATH` in `rag.py` to match the filename.

---

### 4. Add your documents

Put your files into:

```
documents/
```

Supported formats:

* `.txt`
* `.md`
* `.pdf`

---

### 5. Build the vector index

```bash
python ingest.py
```

This reads documents and creates the local FAISS index.

Re-run this whenever documents change.

---

### 6. Start asking questions

```bash
python rag.py
```

Type questions in the terminal. Type `exit` to quit.

## Common error: llama-cpp-python build failure (Windows)

### Error symptoms

During installation, you may see:

```
'nmake' failed with: no such file or directory
CMAKE_C_COMPILER not set
CMAKE_CXX_COMPILER not set
```

### Why this happens

`llama-cpp-python` contains C++ code.

On Windows, Python does **not** ship with a compiler. If pip cannot find a prebuilt wheel, it tries to compile from source and fails.

This is a tooling issue, not a project bug.

---

### Fix option A (try first)

Upgrade pip and prefer prebuilt binaries:

```bash
python -m pip install --upgrade pip
pip install llama-cpp-python --prefer-binary
```

If this works, no further action is needed.

---

### Fix option B (guaranteed fix)

Install Microsoft C++ Build Tools:

1. Download from:
   [https://visualstudio.microsoft.com/visual-cpp-build-tools/](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

2. Install **only**:

   * Desktop development with C++
   * MSVC compiler
   * Windows SDK

3. Restart your system

4. Reinstall:

```bash
pip install llama-cpp-python
```

---

### Verify installation

Run this in Python:

```python
from llama_cpp import Llama
print("llama.cpp loaded")
```

If it prints successfully, the issue is resolved.

## Important notes

* This system does **not train** the model
* Document quality and chunking matter more than model size
* Larger models improve fluency, not retrieval accuracy
* All data stays local
